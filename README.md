# Tarea: Módulo 5 — Halloween

Proyecto realizado por AdanGavira como ejercicio del Módulo 5. Este repositorio contiene una tarea temática de Halloween que incluye recursos estáticos y elementos visuales para una pequeña aplicación interactiva.

## Descripción
Breve proyecto con temática de Halloween pensado para practicar maquetación, estilos y comportamiento con JavaScript. Puede incluir una página informativa, animaciones, efectos visuales y/o minijuego/actividad según el enunciado de la tarea.

## Tecnologías
- JavaFX
- CSS3 (posible uso de animaciones/transiciones)
- Imágenes / recursos estáticos

Esta es la primera pantalla de mi aplicación en la que podemos ver un formulario de inicio de sesión con el nombre, apellidos y un ComboBox para elegir el curso.
Cuando no rellenas todos los campos aparecerá un mensaje en rojo arriba indicando que debes rellenarlos, y cuando todo esta rellenado, al darle al botón, te llevará directamente a la siguiente ventana, que es la ruleta de truco o trato.

Esta es la segunda interfaz en la que podemos ver la ruleta con un botón que pone girar y otro botón abajo a la derecha que sirve para poder volver a la pantalla principal de inicio de sesión. 
La función de esta interfaz es hacer girar la ruleta y tocará truco o trato, y depenediendo del resultado de la ruleta, aparecerá un mensaje u otro.
